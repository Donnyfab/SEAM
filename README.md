# SEAM
Personal music player + EP Transition Studio, installable on iPhone as a PWA.
```
npm i && npm run dev      # http://localhost:5173
npm test && npm run build # production build in dist/
```
Deploy: push to GitHub with Pages enabled (workflow in .github/workflows/pages.yml), open the URL in Safari → Share → Add to Home Screen.
See ARCHITECTURE.md, ROADMAP.md, HANDOFF.md.
